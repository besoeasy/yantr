Get Started

Install Yantr

Yantr runs as a single Docker container. Pick your platform below to see the exact steps, compatibility notes, and the one command you need to run.

Requires Docker. If you don't have Docker installed yet, follow the Docker install guide first — it covers Windows, macOS, Linux, and Raspberry Pi.

Compatibility

✓ Full support Docker socket — /var/run/docker.sock works natively
✓ Full support Port binding -p 5252:5252 works on all distros
✓ Recommended Best overall platform — all features work
1

Run Yantr

bash / zsh
docker run -d \
  --name yantr \
  -p 5252:5252 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  --restart unless-stopped \
  ghcr.io/besoeasy/yantr
2

Open Yantr

Visit http://localhost:5252 and create your operator account on the first visit.

Compatibility

✓ Works Docker socket — Docker Desktop symlinks it to /var/run/docker.sock automatically
✓ Works Port binding -p 5252:5252 works correctly
✗ Not supported --network host — Docker on macOS runs inside a Linux VM, so host networking is unavailable. Use -p instead.
⚠ Colima / OrbStack If using Colima or OrbStack, the socket path may differ. Pass -e DOCKER_SOCKET=/path/to/docker.sock to override.
1

Make sure Docker Desktop is running

Docker Desktop must be open in the menu bar before running Yantr.

Open Yantr

Using Colima or OrbStack?

Find your socket path (e.g. ~/.colima/default/docker.sock) and add -e DOCKER_SOCKET=<your-socket-path> to the command, and mount that path instead of /var/run/docker.sock.

Compatibility

✓ Works Docker Desktop for Windows (WSL2 backend) — the socket is accessible via /var/run/docker.sock inside WSL2
✓ Works Port binding -p 5252:5252 works in PowerShell and WSL2
✗ Not supported --network host — not available on Windows. Use -p instead.
ℹ Recommended Run commands from PowerShell or the WSL2 terminal (not Command Prompt)
1

Make sure Docker Desktop is running

Open Docker Desktop and wait for it to show "Engine running" in the taskbar.

2

Run Yantr — PowerShell

PowerShell
docker run -d `
  --name yantr `
  -p 5252:5252 `
  -v /var/run/docker.sock:/var/run/docker.sock `
  --restart unless-stopped `
  ghcr.io/besoeasy/yantr

Note: PowerShell uses backtick ` for line continuation instead of \

Open Yantr

Compatibility

✓ Full support Raspberry Pi 4 & 5 (arm64) — fully supported
⚠ Partial Raspberry Pi 3 (armv7) — Yantr runs, but some app images may not have arm/v7 builds
✓ Works Docker socket and port binding work the same as on Linux
ℹ Tip Use Raspberry Pi OS 64-bit (Bookworm) for the best compatibility
1

Install Docker on your Pi

Use the official convenience script — it works on Raspberry Pi OS 64-bit:

bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
newgrp docker
2

Run Yantr

bash
docker run -d \
  --name yantr \
  -p 5252:5252 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  --restart unless-stopped \
  ghcr.io/besoeasy/yantr
3

Open Yantr

Visit http://<your-pi-ip>:5252 from any device on your network, or http://localhost:5252 on the Pi itself.

Common Commands

Update Yantr

Pull the latest image and restart

docker pull ghcr.io/besoeasy/yantr
docker stop yantr && docker rm yantr
# then re-run the install command above

Remove Yantr

Stop and delete the container

docker stop yantr
docker rm yantr
# Your deployed app data is kept in Docker volumes
